# DhanMool — Personal & Shared Finance Manager
> *"Your wealth, rooted right."*

DhanMool is an India-first personal and collaborative finance management application built with **React 19**, **FastAPI**, and **Supabase**.

## 🌟 Key Features
1. **Gross Outflow Accounting:** Full payments are logged immediately as outflows, with repayments recorded as incoming settlements.
2. **2-Level Shared Ledgers:**
   - **Level 1 (Continuous):** Ongoing shared living for flatmates, roommates, and joint families.
   - **Level 2 (Event-Scoped):** Specific trip pools (e.g. Goa trip) and festive collections with real-time fair share balances.
3. **1-on-1 Informal Lending (Udhar Tracker):** Standalone IOU ledger for money lent to/borrowed from family and friends with partial/full repayment settlements.
4. **Sinking Fund Event Budgeting with Isolation Toggle:** Sinking funds for Vacations, Weddings, and Festivals that can be isolated from baseline monthly living charts so lifestyle averages aren't skewed.
5. **DhanMool AI Advisor:** Contextual Indian financial intelligence with festival calendar awareness (Diwali, Eid, Rakhi), Section 80C tax planning, and natural language quick transaction logging.
6. **Closed Admin Governance:** User registration is controlled by Super Administrators who provision user accounts from an Admin Console.
